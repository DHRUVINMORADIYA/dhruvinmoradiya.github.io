# dhruvinmoradiya.github.io

Personal site and blog, built with Jekyll and hosted on GitHub Pages at <https://dhruvinmoradiya.github.io>.

## Writing a post

1. Copy `_drafts/post-template.md` into `_posts/` and name it `YYYY-MM-DD-short-slug.md`,
   e.g. `_posts/2026-11-15-what-backprop-taught-me.md`.
2. Fill in the front matter (`title`, `description`, `tags`, `math`).
3. Write in Markdown, then commit and push to `main`. GitHub Pages rebuilds the site in about a minute.

The post is published at `/blog/<short-slug>/`. The date in the filename is the publish date.
Don't rename a file after publishing, because that changes its URL.

Unfinished posts can stay in `_drafts/`. They are never published.

### Front matter

| Field              | Required | Purpose                                                        |
|--------------------|----------|----------------------------------------------------------------|
| `title`            | yes      | Post title                                                     |
| `description`      | yes      | Summary for post lists, link previews and SEO                  |
| `tags`             | no       | List of tags, e.g. `[machine-learning, reflections]`           |
| `math`             | no       | `true` loads MathJax for LaTeX                                 |
| `last_modified_at` | no       | Shows an "Updated" date                                        |
| `image`            | no       | Image used for social link previews, e.g. `/assets/images/x.png` |

### Formatting

- **Code:** fenced blocks with a language name (` ```python `) are syntax highlighted.
- **Math:** set `math: true`, then use `$$...$$` both inline and on separate lines for display math.
  (kramdown doesn't support single `$`.)
- **Images:** put them in `assets/images/<post-slug>/` and reference them as `/assets/images/<post-slug>/file.png`.
- **Callouts:** write a blockquote and put `{: .note}` or `{: .warning}` on the next line.
- **Table of contents:** add `* TOC` followed by `{:toc}` on the next line.
- **Literal `{{ }}` or `{% %}`:** wrap the content in `{% raw %}...{% endraw %}`, because posts are processed by Liquid.

## Site structure

```
_config.yml          site settings, social links, plugins
_data/cards.yml      "Projects & notes" cards on the home page
_layouts/            default (shell) and post layouts
_includes/           reusable snippets (post list, reading time)
_posts/              published posts
_drafts/             unpublished drafts and the post template
assets/css/main.css  all styles (light and dark mode)
blog/index.html      /blog/ – all posts grouped by year
tags.html            /tags/ – posts grouped by tag
```

RSS (`/feed.xml`), the sitemap and SEO meta tags are generated by `jekyll-feed`, `jekyll-sitemap` and `jekyll-seo-tag`.

## Previewing locally (optional)

With Docker:

```sh
docker run --rm -it -p 4000:4000 -v "$PWD:/srv/jekyll" jekyll/jekyll:4.2.2 jekyll serve --drafts
```

With Ruby installed (<https://rubyinstaller.org> on Windows):

```sh
bundle install
bundle exec jekyll serve --drafts --livereload
```

Then open <http://localhost:4000>. `--drafts` also shows the posts in `_drafts/`.
